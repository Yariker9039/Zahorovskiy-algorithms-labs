## Пояснення

Якщо node.children порожній, повертаю node.products. У листка більше немає підкатегорій, які треба обходити.

Базовий випадок — категорія без дітей. Кожний виклик переходить до меншого піддерева дитини. У заданому дереві немає циклів і кількість рівнів скінченна, тому кожна гілка закінчується листком.

12 разів: по одному виклику на кожну категорію, включно з коренем. Перед запуском лічильник обнулено.

У моєму коді залишиться max(...) для порожнього набору дітей. Python видасть ValueError, бо не можна вибрати найбільшу глибину з порожньої послідовності.

На мій погляд, для maxDepth: глибина вузла прямо визначається через найбільшу глибину його дітей. Для обходу циклом довелося б окремо зберігати вузли та їхні рівні. Це виграш у простоті, а не обов’язково у швидкості.
