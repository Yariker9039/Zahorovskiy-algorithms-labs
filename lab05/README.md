# Лабораторна 5

Загоровський Ярослав, ІПЗ-3/1. Python 3.8 або новіший.

Запуск з кореня репозиторію:

```bash
python lab05/main.py
```

У Windows можна використати `py` замість `python`. Додаткові пакети не потрібні.

`main.py` — код, `result.txt` — фактичний вивід перевіреного запуску. Заповнений бланк здається окремо в Classroom.

Сортування стандартне: `sorted`. Український порядок літер задає `surnameKey`. Ключі: прізвище, мінус бал, пара (група, мінус бал). Для однакових балів з абеткою: (мінус бал, surnameKey). `sorted` зберігає початковий порядок однакових ключів.
