## Пояснення

Перед stack.pop() є if not stack: return False. Без цієї перевірки на рядку a) програма спробує взяти дужку з порожнього deque й отримає IndexError.

Після ( і [ на вершині стека лежить [. Далі приходить ), якій потрібна (. Типи не збігаються: пари перетинаються.

У ньому немає зайвих або незакритих дужок. Цикл не виконується, стек лишається порожнім, тому повертається True.

Заявки підуть у зворотному порядку: першим буде «Студентський квиток», останньою — «Довідка про навчання». Початки будуть 0, 3, 12, 18, 20, 27 хв; загальний час лишиться 31 хв.

Остання заявка чекала 28 хв: 4 + 7 + 2 + 6 + 9. Середнє очікування всіх шести: (0 + 4 + 11 + 13 + 19 + 28) / 6 = 12,5 хв. Усі заявки вже стоять у черзі на початку.
